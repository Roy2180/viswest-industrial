# VisWest Industrial Services — Website Prototype

A static, responsive prototype for the proposed VisWest Industrial Services business.

## Files
- `index.html` — site content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu and disabled prototype form behaviour
- `.nojekyll` — tells GitHub Pages to serve the files as-is

## Publish free with GitHub Pages
1. Create a new **public** repository, e.g. `viswest-industrial`.
2. Upload these files to the repository root and commit them to `main`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will publish the project at a URL similar to:
   `https://YOUR-USERNAME.github.io/viswest-industrial/`

## Before commercial launch
Replace prototype wording only after the company has been established and the statements are accurate. Add:
- legal company name
- ABN/ACN
- business email and phone
- insurance/licensing claims only when current and verified
- privacy notice before collecting worker details
- a real form backend (e.g. a secure recruitment form or ATS)

Do not display customer/client logos without permission.
